## 기존 원고와 정정 안내

**기존 5 쪽 HWP·PDF는 원문 그대로 보존합니다.** 원고 그림의 세 값에 남은 이중 반올림 표시와 반복 문단을 별도 [논문 정정 안내](../../발표자료/5차/논문_정정안내.pdf)에서 구분해 설명합니다.

발표 그래프는 저장된 원정밀도 값에서 한 번 반올림한 표시를 사용합니다.

원고를 인용할 때 이 안내를 함께 확인합니다.


**같은 연구의 3쪽 축약 본·5 쪽 전체 본·별도 요약이 있던 최종 단계에서 현재는 5 쪽 전체 원고와 같은 판의 HWP를 제공합니다.**

<a id="-이-자료를-읽는-순서"></a>

## 이 자료를 읽는 순서

1. 초록과 방법에서 단일·복합 필터의 연구 질문을 확인합니다.
2. 자료 분할과 조건별 재학습 여부를 읽고 평가 단위를 구분합니다.
3. 단일·복합·잡음·반복 결과를 표별로 비교하고 기준 Original과의 차이를 봅니다.
4. Strict Acc의 정의와 내부 train/val 중복 한계를 확인한 뒤 결과를 인용합니다.

<a id="-연결된-내용"></a>

## 연결된 내용

| 구성 | 읽을 내용 |
| --- | --- |
| 전체 원고 선택 | 5 쪽은 연구의 방법·조건·표·해석을 담은 전체 본문이며 3쪽 축약 본으로 대체하지 않습니다. |
| 원고 계보 | 최 종 5 쪽 HWP는 3차 HWP와 같습니다.<br>작성·축약 형식의 차이를 새 연구로 세지 않습니다. |
| 필터 비교 | 단일 10 종과 순차 복합 5 종을 Original 기준과 비교합니다. |
| 조건별 재학습 | 미지 촬영 조건에 고정 모델을 바로 적용한 평가와 구분합니다. |
| 두 지표 | 경계 상자 mAP50-95와 모든 볼을 맞추고 추가 검출이 없는 Strict Acc를 구분합니다. |
| 반복과 잡음 | 일반 조건과 잡음 표준편차 40·80, 세 시드 반복을 나누어 읽습니다. |

<a id="-해석-범위"></a>

## 해석 범위

일반 영상 단일 시드에서 Gamma0.3의 mAP50-95는 96.70%, Original은 96.53%로 원고가 보고합니다.

차이는 0.17%p이며 작은 차이를 무조건적인 우위로 확대하지 않습니다.
