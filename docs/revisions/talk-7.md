## LEVEL 1 - Beginner

### LEVEL 1 · 감사 인사에 집중하는 마지막 장

**변경 대상은 마지막 장의 보조 문구와 안내입니다.** 발표 끝에 남는 글과 선을 줄여 감사 인사가 먼저 보이도록 정리했습니다. 질의응답이라는 글자와 아래쪽 네 파트 이름·선을 지웠습니다. 감사 인사, 발표자 이름, 학교 마크, 페이지 번호는 유지했습니다.

| 구분 | 변경 | 보존 |
| --- | --- | --- |
| 마지막 장 | 질의응답 문구 · 네 파트 라벨 · 네 선 삭제 | 감사 인사 · 저자 · 학교 마크 · 페이지 번호 |
| 1~19장 | 변경 없음 | 설명·사진·그래프·연구 수치 |
| 연습 자료 | 기존 파일 사용 | 5차 대본·질문 답변·연구 이해·정정 안내 |

발표 내용은 같은 20장입니다. 1~19장의 사진·그래프·설명과 마지막 장에서 읽는 대본도 그대로 사용합니다. 7차 PDF를 열어 마지막 장을 확인하고, 5차 대본과 질문 자료로 발표를 준비하면 됩니다. 사진에서 볼 위치를 찾는 실험 결과를 새로 만든 작업은 아닙니다.

## LEVEL 2 - Explorer

### LEVEL 2 · 마무리 화면의 정보 우선순위

**변경 대상은 마지막 장의 보조 문구와 안내입니다.** 마지막 장의 역할을 감사 인사로 좁혀 보조 내비게이션과 문구를 줄였습니다. 네 파트 안내는 앞선 연구 흐름을 나타내던 표시이며, 마지막 장에서 이를 지워도 연구 배경·방법·결과·결론의 내용은 바뀌지 않습니다.

| 구분 | 변경 | 보존 |
| --- | --- | --- |
| 마지막 장 | 질의응답 문구 · 네 파트 라벨 · 네 선 삭제 | 감사 인사 · 저자 · 학교 마크 · 페이지 번호 |
| 1~19장 | 변경 없음 | 설명·사진·그래프·연구 수치 |
| 연습 자료 | 기존 파일 사용 | 5차 대본·질문 답변·연구 이해·정정 안내 |

같은 20장 순서와 장별 발화를 사용하므로 기존 대본·질문과 답변을 이어 읽습니다. 슬라이드 시각 요소의 삭제와 실험 조건·결과의 변경을 구분합니다. 조건별 재학습과 두 평가 지표의 정의, 반복 평가의 한계는 이전 차수와 같습니다.

## LEVEL 3 - Practitioner

### LEVEL 3 · 현재 파일과 기존 연습 자료의 연결

**변경 대상은 마지막 장의 보조 문구와 안내입니다.** 7차 PPTX는 편집·상영 원본이고 PDF는 같은 슬라이드의 열람 본입니다. 마지막 장의 질의응답 문구, 하단 네 파트 라벨과 네 안내선을 제거했습니다. 감사 인사·저자·학교 마크·페이지 번호를 확인한 뒤 상영 파일로 사용합니다.

| 구분 | 변경 | 보존 |
| --- | --- | --- |
| 마지막 장 | 질의응답 문구 · 네 파트 라벨 · 네 선 삭제 | 감사 인사 · 저자 · 학교 마크 · 페이지 번호 |
| 1~19장 | 변경 없음 | 설명·사진·그래프·연구 수치 |
| 연습 자료 | 기존 파일 사용 | 5차 대본·질문 답변·연구 이해·정정 안내 |

발표 전에는 PDF 20쪽과 PPTX 20장 순서가 맞는지 확인합니다. 1~19장은 6차와 같고, 대본과 사진·수치는 유지했습니다. 5차 10분 대본·질문 답변·답 없는 연습 질문지·연구 이해 자료를 같이 사용하고 실제 발화 시간은 리허설에서 측정합니다.

## LEVEL 4 - Advanced

### LEVEL 4 · 마지막 슬라이드로 제한한 수정 경계

**변경 대상은 마지막 장의 보조 문구와 안내입니다.** 수정은 마지막 장의 표시 요소 아홉 개에 한정했습니다. 질의응답 문구 하나, 네 파트 라벨 네 개, 안내선 네 개를 제거하고 다른 표시 요소를 보존했습니다. 앞선 19장과 자료·도표·숫자를 바꾸는 작업으로 확장하지 않았습니다.

| 구분 | 변경 | 보존 |
| --- | --- | --- |
| 마지막 장 | 질의응답 문구 · 네 파트 라벨 · 네 선 삭제 | 감사 인사 · 저자 · 학교 마크 · 페이지 번호 |
| 1~19장 | 변경 없음 | 설명·사진·그래프·연구 수치 |
| 연습 자료 | 기존 파일 사용 | 5차 대본·질문 답변·연구 이해·정정 안내 |

PPTX의 슬라이드 내용과 PDF 렌더링을 대조하며 마지막 장의 남은 구성과 제거 대상을 확인합니다. 기존 6차 PPTX·PDF와 5차 준비 자료는 보존합니다. 이번 차수는 화면 편집이며 새 학습·추론·성능 검증 결과를 추가하지 않습니다.

## LEVEL 5 - Expert

### LEVEL 5 · 패키지 차이와 연구 근거의 불변성

**변경 대상은 마지막 장의 보조 문구와 안내입니다.** PPTX의 마지막 슬라이드에서 질의응답과 하단 파트 라벨·선에 해당하는 아홉 shape를 삭제한 변경입니다.

감사 인사·저자·마크·페이지 번호와 다른 19장 및 노트·사진·연구 수치를 보존합니다.

공개 전체 비교에는 텍스트 변경 줄과 바이너리 크기·SHA-256을 함께 기록합니다.

| 구분 | 변경 | 보존 |
| --- | --- | --- |
| 마지막 장 | 질의응답 문구 · 네 파트 라벨 · 네 선 삭제 | 감사 인사 · 저자 · 학교 마크 · 페이지 번호 |
| 1~19장 | 변경 없음 | 설명·사진·그래프·연구 수치 |
| 연습 자료 | 기존 파일 사용 | 5차 대본·질문 답변·연구 이해·정정 안내 |

500개 영상에 대한 기존 조건별 재학습 평가와 지표 정의·내부 그룹 분리의 한계는 그대로 적용됩니다. Gamma 단일 시드의 소폭 차이, 합성 잡음 비교, 일부 세 시드 반복의 해석을 바꾸지 않습니다. 마지막 장의 정리로 일반화 성능이나 실제 발화 시간이 개선되었다고 측정한 것은 아닙니다.
