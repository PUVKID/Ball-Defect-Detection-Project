### LEVEL 1·20장 순서에 맞춘 전체 발화 문

**20장 순서에 맞춘 전체 발화 문**을 읽는 단계입니다.

<a id="-읽고-활용하는-순서"></a>

## 원고 읽기

1. 최종 발표 PDF를 열고 대본을 같은 장 순서로 읽습니다.
2. 각 구간에서 설명하는 지표와 그림을 확인합니다.
3. 전환 문장이 다음 장의 연구 질문과 연결되는지 확인합니다.
4. 리허설에서 실제 시간을 측정해 말하기 속도와 쉬는 구간을 맞춥니다.

<a name="results"></a>

<a id="-결과를-읽는-방법"></a>

## 결과와 해석

문장과 시간 배분은 발표 구성입니다. 실제 발표 시간·성적·성능 측정을 보고하는 파일은 아닙니다.

기존 3 →4차 비교는 당시 공개 텍스트 기준의 변화이고 현재 파일은 원문 대본입니다. 현재 파일과 직전 공개 본의 차이는 저 장소 변경 기록으로 구분합니다.
