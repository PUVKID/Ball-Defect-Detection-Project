## LEVEL 1 - Beginner

### LEVEL 1 · 사진 손질 방법을 비교한 발표

**저장된 연구 결과를 발표에 맞게 다시 정리한 차수입니다.** 사진에서 공처럼 생긴 작은 볼의 위치를 찾는 AI를 다뤘습니다.

사진을 밝게 바꾸거나, 가장자리를 강조하거나, 흐리게하는 방법을 각각 비교합니다.

필터는 사진을 손질하는 방법이고, 검출은 볼마다 네모 상자를 붙여 위치를 찾는 일입니다.

같은 사진 손질 방법으로 AI도 다시 공부시킨 뒤 시험한 결과이므로, 이미 만들어진 AI에 아무 사진이나 넣어도 같은 점수가 나온다는 뜻은 아닙니다.

| 구성 | 역할 | 확인할 점 |
| --- | --- | --- |
| 슬라이드 PPTX·PDF | 연구 배경·방법·필터별 비교·결론 전달 | 같은 발표의 편집본과 열람본 |
| 10분 대본 PDF | 장별 발화와 전환 설명 | 600초는 목표 배분, 실제 시간은 리허설 |
| 예상 질문·답변 PDF | 높은 점수·분할·지표·범위 설명 | 원인 확정과 가능한 설명을 구분 |
| 연구 이해 자료 PDF | 용어·비교 결과·발표 주의점 설명 | 새로운 실험 성과로 해석하지 않기 |
| 발표연습 질문지 PDF | 답을 보지 않고 질의응답 연습 | 예상 질문과 답변으로 자체 확인 |

발표 PDF를 먼저 훑고, 대본의 같은 장을 읽은 다음 질문과 답변으로 확인합니다. 그래프의 높은 점수는 위치를 찾는 평가 점수입니다. 모든 사진이 완벽하게 맞았다는 뜻은 아닙니다. Original의 Strict Acc 94.8%는 500장 중 474장에서 볼을 빠뜨리거나 더 찾는 오류가 없었다는 의미입니다.

| 단계 | 변화 | 연구 결과와의 관계 |
| --- | --- | --- |
| 3차 슬라이드·4차 대본 | 기존 연구를 20장·10분 목표로 설명 | 기존 자료를 보존 |
| 5차 발표 자료 | 가독성과 자료 간 대응을 보강 | 추가 학습·새 측정 없음 |

## LEVEL 2 - Explorer

### LEVEL 2 · 필터와 재학습의 관계

**저장된 연구 결과를 발표에 맞게 다시 정리한 차수입니다.** 입력 영상의 표현을 바꾸면 학습 모델이 보는 단서도 달라집니다.

이번 비교는 Original과 열 가지 단일 필터, 순서를 정한 다섯 복합 필터를 같은 외부 교차 검증 구조에서 비교한 것입니다.

합성 잡음은 별도 조건입니다.

동일 필터·잡음 조건을 학습과 평가에 적용하므로, 필터만의 효과와 조건별 재학습의 적응을 분리한 실험으로 해석하면 안 됩니다.

| 발표연습 질문지 PDF | 답을 보지 않고 질의응답 연습 | 예상 질문과 답변으로 자체 확인 |

mAP50-95는 경계 상자의 위치와 검출을 여러 IoU 기준에서 평가합니다. Strict Acc는 중심 거리로 볼을 일대일 대응시키고 누락·추가 검출이 모두 없는 영상의 비율입니다. 두 지표에서 순위가 달라질 수 있으며, 발표는 일반 조건과 잡음 조건을 나누어 이 관계를 설명합니다.

## LEVEL 3 - Practitioner

### LEVEL 3 · 발표와 질의응답을 준비하는 순서

**저장된 연구 결과를 발표에 맞게 다시 정리한 차수입니다.** PPTX는 편집용, 같은 발표 PDF는 열람·상영 확인용입니다.

장별 대본과 질문·답변은 PDF로 읽습니다.

논문과 원정밀도 CSV/JSON을 함께 두고 슬라이드의 조건과 분모를 대조합니다.

새 모델 학습이나 추론을 하지 않고 기존 저장 결과를 바탕으로 설명 자료를 다시 구성했습니다.

| 구성 | 역할 | 확인할 점 |

| 발표연습 질문지 PDF | 답을 보지 않고 질의응답 연습 | 예상 질문과 답변으로 자체 확인 |

발표 전에는 PPTX와 PDF의 장 순서, 슬라이드와 대본의 제목, 그림의 영어 필터 이름과 축 단위를 확인합니다. 목표 시간은 600초지만 실제 발화 시간은 리허설로 확인해야 합니다. 소수 첫째 자리 백분율은 반올림한 표시이며, 작은 개선 폭을 비교할 때는 저장 원값을 확인합니다.

## LEVEL 4 - Advanced

### LEVEL 4 · 전달 구조와 결과의 경계

**저장된 연구 결과를 발표에 맞게 다시 정리한 차수입니다.** 발표의 사진은 입력 변환의 예시이며 전체 시험 결과를 대신하지 않습니다.

본문 그래프는 저장된 집계값을 사용합니다.

그래프의 글자·축·범례가 읽히도록 배치와 강조를 조정하고, 한 장에서 비교할 대상을 제한합니다.

기존 연구 코드·데이터·모델의 동작을 변경한 차수가 아닙니다.

| 구성 | 역할 | 확인할 점 |
| --- | --- | --- |
| 슬라이드 PPTX·PDF | 연구 배경·방법·필터별 비교·결론 전달 | 같은 발표의 편집본과 열람본 |
| 10분 대본 PDF | 장별 발화와 전환 설명 | 600초는 목표 배분, 실제 시간은 리허설 |
| 예상 질문·답변 PDF | 높은 점수·분할·지표·범위 설명 | 원인 확정과 가능한 설명을 구분 |
| 연구 이해 자료 PDF | 용어·비교 결과·발표 주의점 설명 | 새로운 실험 성과로 해석하지 않기 |
| 발표연습 질문지 PDF | 답을 보지 않고 질의응답 연습 | 예상 질문과 답변으로 자체 확인 |

일반 조건에서 Gamma가 기록한 mAP50-95 96.701438764475와 Original 96.52799766716707의 차이는 약 0.17%p입니다.

Gamma의 일반 조건 반복 평가가 없어 안정적인 우위라고 단정하지 않습니다.

복합 필터는 평가 한 다섯 순서만 비교했으므로 모든 조합·반대 순서의 결론으로 확장하지 않습니다.

## LEVEL 5 - Expert

### LEVEL 5 · 평가 프로토콜과 재현 한계

**저장된 연구 결과를 발표에 맞게 다시 정리한 차수입니다.** 500개 영상·6,270개 볼 상 자, 368개 유사 그룹 기반 외부 5 겹 교차 검증 결과를 설명합니다.

외부 평가의 알려진 그룹 중복은 0이나 내부 train/val에는 9~20개 유사 그룹 중복이 남아 있습니다.

이는 모델 선택의 독립성에 대한 한계이며 저장 결과가 잘못되었다거나 높은 점수의 원인이 확정되었다는 증거는 아닙니다.

| --- | --- | --- |
| 슬라이드 PPTX·PDF | 연구 배경·방법·필터별 비교·결론 전달 | 같은 발표의 편집본과 열람본 |

| 발표연습 질문지 PDF | 답을 보지 않고 질의응답 연습 | 예상 질문과 답변으로 자체 확인 |

mAP는 fold별 held-out test의 AP를 평균한 값이고, Strict Acc는 전체 500장에 대해 누락·추가 검출이 없는 영상을 합산한 비율입니다.

세 시드 반복에서는 분할·학습 난수·잡음 실현이 함께 달라집니다.

평균 ± 표본 표준 편차는 신뢰구간이 아니며, 반복 횟수 3 만으로 유의성을 주장하지 않습니다.

외부 촬영 자료 평가와 원 AP 재계산은 이번 발표 개정에서 수행하지 않았습니다.
