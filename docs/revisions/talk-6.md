## LEVEL 1 - Beginner

### LEVEL 1 · 발표 그림을 읽기 쉽게 정리

같은 연구를 설명하는 20장 발표의 시각 표현을 개정했습니다. 이 연구는 사진에서 볼의 위치를 찾는 AI에 사진 손질 방법을 달리 적용해 결과를 비교했습니다.

사진 손질 방법을 필터라고 합니다.

이번 6차에서는 같은 실험 결과를 발표할 때 어디까지가 배경이고 어디부터가 방법·결과인지 구분하기 쉽게 다듬었습니다.

선으로 이어진 도식은 입력 사진이 처리되어 평가되는 순서를 보여 줍니다.

| 시각 요소 | 맡는 역할 | 유지할 근거 |
| --- | --- | --- |
| 파트 구분 | 배경·방법·결과·결론의 흐름 표시 | 같은 20장 내용과 장별 순서 |
| 도식 연결선 | 입력·처리·평가 관계 표시 | 실제 연구 절차와 화살표 방향 |
| 필터별 색 | 필터 비교 대상 구분 | 영어 이름과 실제 관측값 |
| 계열 표식·대비 | 같은 그래프의 다른 계열 구분 | 범례·표식·축 단위의 대응 |

차트의 색은 필터나 계열을 눈으로 구분하는 보조 수단입니다. 색이 진하거나 새 색을 썼다고 점수가 더 높아졌다는 뜻은 아닙니다. 필터 이름·숫자·축 단위를 함께 읽으셔야합니다. 6차 발표 PDF를 먼저 읽고 5차 10분 대본의 같은 장을 따라가면 됩니다.

| 자료 | 사용 방법 | 해석 범위 |
| --- | --- | --- |
| 6차 PPTX·PDF | 같은 슬라이드를 편집하거나 열람 | 새 연구 결과 없음 |
| 5차 대본·질의 응답 자료 | 같은 장 순서로 설명·연습 | 600초 목표와 실제 시간 구분 |
| 기존 원고·정정 안내 | 원문과 표시 정정 범위를 함께 읽기 | 원고 본문과 원정밀도 보존 |

## LEVEL 2 - Explorer

### LEVEL 2 · 연구 이야기와 비교 대상을 구분

같은 연구를 설명하는 20장 발표의 시각 표현을 개정했습니다. 발표는 배경에서 연구 질문을 제시하고, 자료·조건과 평가 방법을 설명한 뒤 필터별 결과와 한계를 전달합니다.

이 흐름을 파트별로 나누고 도식의 연결 관계를 명료하게 했습니다.

동일한 결과값에 표현 방식을 바꾼 것이므로 그래프의 색·기호가 추가 실험 조건을 뜻하지 않습니다.

필터별 색과 계열 표식을 함께 보면 비교 대상을 구분하기 쉽습니다. 범례·라벨·표식·색을 서로 맞춰 읽고, 일반 조건의 단일 시드와 잡음·일부 반복 조건을 혼동하지 않습니다. 모델은 필터·잡음 조건마다 다시 학습한 비교였으며 미지 현장의 고정 모델 성능을 입증한 실험은 아닙니다.

## LEVEL 4 - Advanced

### LEVEL 4 · 시각 표현의 변경 경계

같은 연구를 설명하는 20장 발표의 시각 표현을 개정했습니다. 내용 구조를 바꾸는 파트 구분, 노드 사이의 처리 순서를 보여 주는 연결선, 필터 단위 색, 계열 간 대비와 표식을 시각 요소로 다뤘습니다.

그래프 값과 축의 의미는 같은 연구 결과를 전달하도록 유지합니다.

코드·원자료·원고·대본을 새 실험으로 바꾸지 않습니다.

## LEVEL 5 - Expert

### LEVEL 5 · 데이터 불변성과 해석 범위를 대조

같은 연구를 설명하는 20장 발표의 시각 표현을 개정했습니다. 6차 변경 대상은 발표 시각 표현과 이를 설명하는 공개 문서입니다. 원 정밀도 집계와 20장 내용·대본, 기존 5차 자료·원고·정정 안내를 보존합니다. PPTX의 차트 값과 PDF 표시, 도식 연결·범례·표식의 의미가 서로 일치해야 합니다.
