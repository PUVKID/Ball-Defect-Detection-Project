<a id="-이-자료를-읽는-순서"></a>

## 이 자료를 읽는 순서

1. 이 차수의 변경 설명을 읽고 현재 최종 PDF에서 대응되는 발표 흐름을 봅니다.
2. 도입·방법·필터 비교·잡음·한계가 어떤 순서로 전달되는지 확인합니다.
3. PPTX 노트와 완성 대본의 장별 발화를 확인합니다.
4. 검사 도구를 이용하려면 입력 JSON·원자료·발표 파일의 경로를 먼저 준비합니다.

<a id="-연결된-내용"></a>

## 연결된 내용

**구성**

내용 유지

**읽을 내용**

2·3차 content.json은 같은 바이트여서 발화 내용·시간 배정은 유지됩니다.


**구성**

자산 점검

**읽을 내용**

RGBA 투명 로고·동봉 PNG/SVG/원본 AI와 입력 보존을 대조하는 조건을 추가합니다.


**구성**

원정밀도 차트

**읽을 내용**

검사기는 JSON 수치와 PPTX 차트의 15유효자리 및 1·2자리 표시를 대조합니다.


**구성**

발화 대응

**읽을 내용**

슬라이드 노트와 대본에 같은 발화문이 있는지 확인하는 경로를 포함합니다.



<a id="-해석-범위"></a>

## 해석 범위

600초는 슬라이드에 배정한 목표 시간입니다. 실제 발화 시간이나 발표 평가 점수를 뜻하지 않으므로 리허설에서 확인합니다.
