## 🔎 범위와 해석

수치는 연구 원고에 보고된 값입니다.


## 🧩 주요 내용

- 단일 실행 Gamma mAP50-95 96.70%와 원본 96.53%를 보고합니다. Strict Acc는 별도 중심 일치 규칙의 지표입니다.
- 필터·잡음 조건마다 재학습하고 세 시드로 반복 비교했습니다. 내부 학습·검증 분할에는 유사 그룹 중복이 남아 있습니다.

## 🔄 자료 구성
