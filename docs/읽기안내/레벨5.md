## 최신 발표·7차·LEVEL 5

PPTX의 마지막 슬라이드에서 질의응답과 하단 파트 라벨·선에 해당하는 아홉 shape를 삭제한 변경입니다. 감사 인사·저자·마크·페이지 번호와 다른 19장 및 노트·사진·연구 수치를 보존합니다. 공개 전체 비교에는 텍스트 변경 줄과 바이너리 크기·SHA-256을 함께 기록합니다.

500개 영상에 대한 기존 조건별 재학습 평가와 지표 정의·내부 그룹 분리의 한계는 그대로 적용됩니다. Gamma 단일 시드의 소폭 차이, 합성 잡음 비교, 일부 세 시드 반복의 해석을 바꾸지 않습니다. 마지막 장의 정리로 일반화 성능이나 실제 발화 시간이 개선되었다고 측정한 것은 아닙니다.

## 최신 발표·6차·LEVEL 5

6차 변경 대상은 발표 시각 표현과 이를 설명하는 공개 문서입니다. 원 정밀도 집계와 20장 내용·대본, 기존 5차 자료·원고·정정 안내를 보존합니다. PPTX의 차트 값과 PDF 표시, 도식 연결·범례·표식의 의미가 서로 일치해야 합니다.

500개 영상에 대한 기존 조건별 재학습 평가, 외부 유사 그룹 기반 5 겹 교차 검증과 내부 train/val 그룹 중복의 한계가 그대로 적용됩니다.

일반 조건 Gamma의 작은 단일 시드 차이를 안정적인 우위로 바꾸지 않습니다.

소수 첫째 자리 백분율은 표시용 반올림이며, 신뢰구간·통계적 유의성·미지 현장 검증을 새로 주장하지 않습니다.

## 최신 발표 자료 · LEVEL 5

500개 영상·6,270개 볼 상 자, 368개 유사 그룹 기반 외부 5 겹 교차 검증 결과를 설명합니다.

외부 평가의 알려진 그룹 중복은 0이나 내부 train/val에는 9~20개 유사 그룹 중복이 남아 있습니다.

이는 모델 선택의 독립성에 대한 한계이며 저장 결과가 잘못되었다거나 높은 점수의 원인이 확정되었다는 증거는 아닙니다.

mAP는 fold별 held-out test의 AP를 평균한 값이고, Strict Acc는 전체 500장에 대해 누락·추가 검출이 없는 영상을 합산한 비율입니다.

세 시드 반복에서는 분할·학습 난수·잡음 실현이 함께 달라집니다.

평균 ± 표본 표준 편차는 신뢰구간이 아니며, 반복 횟수 3 만으로 유의성을 주장하지 않습니다.

외부 촬영 자료 평가와 원 AP 재계산은 이번 발표 개정에서 수행하지 않았습니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

라벨 볼과 예측 볼의 일대일 매칭, 부품 영역 판정, 전문가 영상 정답은 별개 평가 계층입니다. 정답 상자에 동일 규칙을 적용한 대리 정답의 타당성을 별도 검증 없이 전문가 판정으로 동일시하지 않습니다.

<a id="guide-flow"></a>

## 입력·처리·출력

외부 평가 분할과 내부 모델 선택 분할의 단위를 구분합니다. 내부에는 9~20개 그룹 중복이 남아 있으며 조건마다 재학습합니다. 필터 처리·학습·중심 매칭·Strict Acc와 held-out model.val mAP의 정의를 각각 고정합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

고정된 입력·라벨·그룹·시드·필터 파라미터와 결과 파일 계보를 대조합니다. 원정 밀도 CSV/JSON과 반올림 그래프를 분리하고 단일 시드와 반복 실험을 혼합 집계하지 않습니다. 검토 도구의 검사 대상과 연구 주장 범위를 구분합니다.

<a id="guide-results"></a>

## 관측 결과와 해석

96.70% 대 96.53%의 0.17%p 차이는 해당 일반 영상 단일 시드의 보고값입니다. 내부 중복과 조건별 재학습, 독립 촬영 로트 부재를 함께 기술합니다. 통계적 유의성·현장 일반화·전문가 판정 정확도를 새로 추정하지 않습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

아티팩트 검토는 라벨 계보·분할 함수·중심 매칭·캐시 서명·held-out 평가를 연결합니다. 최종 노트북 추가 진단과 이전 저장 결과는 같은 범위가 아닙니다. 실행 환경·제조 원자료·가중치가 자동 제공된다고 가정하지 않습니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

논문·발표·실행 코드의 계보와 주장 범위를 나눕니다. 최종 20장 발표의 현재 연결과 과거 차수의 당시 파일 기록을 함께 보존합니다. 문서 편집·검토 성공이 원고 제출 승인이나 성능 입증을 뜻하지 않습니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

외적 타당성·내부 선택 편향·지표 구성개념·대리 라벨의 한계를 함께 검토합니다. 실측 없는 촬영 로트나 전문가 평가 성능을 추정하지 않습니다. 원문 보고값과 구현의 추가 진단을 분리해 근거 수준을 유지합니다.

### LEVEL 5 · 영상 크기와 학습·분할 조건

2944×2352/500영상·400/100초기 분할·368 그룹 5fold·내부 중복·30epoch/1280/b8/p15를 각각 명세화합니다. 그룹 평가와 조건별 재학습의 범위를 유지하며 독립 촬영 로 트·고정 공격 조건 일반화의 증거로 확대하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 영상 500장·2944×2352 | 초기에는 학습 400장·검증 100장으로 나눕니다.<br>사진 크기와 장수는 서로 다른 단위이며, 볼 상자 라벨이 별도로 필요합니다. |
| <a id="layout18-table-3-row-2"></a> 368개 근접 중복 그룹·외부 5fold | 닮은 사진이 바깥 평가의 학습/시험 양쪽에 퍼지지 않도록 그룹으로 묶어 다섯 겹 비교를 합니다.<br>그러나 내부 train/val에는 9~20개 유사 그룹 중복이 남아 결과가 낙관적일 수 있습니다. |
| <a id="layout18-table-3-row-3"></a> YOLOv8n·30epoch·입력 1280·batch8·patience15 | 입력은 모델에 넣을 크기,batch는 한 갱신에 묶는 영상 수,epoch는 전체 자료 반복 단위입니다.patience15는 개선을 기다리는 조기 종료 설정입니다.<br>최대한 도와 실제 종료를 구분합니다. |

### LEVEL 5·상자 검출·Strict Acc·OK/NG의 차이

mAP conf.001/NMS.7,Strict conf.25/NMS.5·주석긴변. 5 중심 거리·일대일 대응·완전 검출 분모를 고정합니다. 규칙 정답과 전문가 정답을 분리하고 다수 기준/McNemar의 비교 단위를 유지합니다. 세 지표를 단일 결함 정확도로 치환하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> mAP50-95 조건 | conf0.001·NMS IoU0.7로 볼 상자 검출을 평가합니다.conf는 예측을 남길 신뢰 도 문턱,NMS IoU는 겹친 예측을 정리하는 기준입니다.<br>평가 이름의 IoU 범위와 NMS 설정을 혼동하지 않습니다. |
| <a id="layout18-table-4-row-2"></a> Strict Acc 조건 | conf0.25·NMS IoU0.5입니다.<br>주석/예측 중심을 가까운 순서로 일 대 일 대응시키며 허용 거리는 주석 상자 긴 변의 0.5 배입니다.<br>볼을 모두 찾고 추가 검출도 없는 영상 비율입니다. |
| <a id="layout18-table-4-row-3"></a> 별도 OK/NG 규칙 | 중앙 부품 영역에서 위 5·왼쪽 4·아래 2·오른쪽 2개 규칙으로 판정합니다.<br>라벨 상자에도 같은 규칙을 적용한 정답과의 일치율은 전문가의 별도 불량 판정 정확도가 아닙니다. |
| <a id="layout18-table-4-row-4"></a> 평가의 기준과 보조 분석 | mAP는 상자의 겹침,Strict는 중심 대응·누락/추가, OK/NG는 개수 규칙을 평가합니다.<br>다수 클래스 기준은 불균형의 단순 기준,McNemar 는 같은 영상에 대한 두 방법의 정오답 차이를 봅니다.<br>실제 정답 CSV를 쓸 때 OKNG_CSV·REAL_LABEL_*을 확인합니다. |
