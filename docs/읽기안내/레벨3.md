## 최신 발표·7차·LEVEL 3

7차 PPTX는 편집·상영 원본이고 PDF는 같은 슬라이드의 열람 본입니다. 마지막 장의 질의응답 문구, 하단 네 파트 라벨과 네 안내선을 제거했습니다. 감사 인사·저자·학교 마크·페이지 번호를 확인한 뒤 상영 파일로 사용합니다.

발표 전에는 PDF 20쪽과 PPTX 20장 순서가 맞는지 확인합니다. 1~19장은 6차와 같고, 대본과 사진·수치는 유지했습니다. 5차 10분 대본·질문 답변·답 없는 연습 질문지·연구 이해 자료를 같이 사용하고 실제 발화 시간은 리허설에서 측정합니다.

## 최신 발표·6차·LEVEL 3

6차 PPTX는 편집·상영용이고 PDF는 동일한 슬라이드의 열람 본입니다. 20장 순서와 장별 발화 내용은 유지하여 5차 대본을 같이 사용합니다. 질문·답변, 답 없는 발표 연습 질문지, 연구 이해 자료와 논문 정정 안내도 5차 파일을 이어 씁니다.

발표 전에는 PPTX와 PDF의 장 순서, 도식의 화살표 방향, 차트 라벨·범례·표식의 대응과 작은 글씨를 확인합니다. 600초는 목표 시간이고 실제 말하는 시간은 리허설로 확인해야 합니다. 이번 차수에서 원본 영상 추론이나 학습은 수행하지 않았습니다.

| 차수 | 달라진 부분 | 자료 |

| 발표 자료 6차 | 파트 구분·도식 연결 선·필터 색·계열 식별 | [같은 수준 설명](../revisions/talk-6.md#reading-level-3) · [폴더](../../발표자료/6차) · [직전 비교](../revision-diffs/talk-6.md) |

## 최신 발표 자료 · LEVEL 3

PPTX는 편집용, 같은 발표 PDF는 열람·상영 확인용입니다. 장별 대본과 질문·답변은 PDF로 읽습니다. 논문과 원정 밀도 CSV/JSON을 함께 두고 슬라이드의 조건과 분모를 대조합니다. 새 모델 학습이나 추론을 하지 않고 기존 저장 결과를 바탕으로 설명 자료를 다시 구성했습니다.

발표 전에는 PPTX와 PDF의 장 순서, 슬라이드와 대본의 제목, 그림의 영어 필터 이름과 축 단위를 확인합니다. 목표 시간은 600초지만 실제 발화 시간은 리허설로 확인해야 합니다. 소수 첫째 자리 백분율은 반올림한 표시이며, 작은 개선 폭을 비교할 때는 저장 원값을 확인합니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

OKNG_CSV의 유무와 정답 정의를 먼저 확인합니다. 경계 상자 라벨 기반 판정, mAP, 누락·추가·위치 오류를 별도로 읽으세요. 어떤 지표가 실제 전문가 라벨과 비교했는지 기록해야 합니다.

<a id="guide-flow"></a>

## 입력·처리·출력

A +B는 A 뒤 B 적용 순서입니다. 일반 영상은 원본·단일·복합, 노이즈는 원본·단일 필터 범위입니다. 파라미터는 원문 설정이며 모든 역 순·가능 조합이나 최적 값 탐색을 뜻하지 않습니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

train_per_filter와 inference_only 모드, 자료·가중치·임계 값·필터 서명 기반 캐시를 확인합니다. 기존 결과 열람과 재실행을 분리하세요. 단순 도구 검사 통과를 논문 제출이나 성능 승인으로 바꾸지 않습니다.

<a id="guide-results"></a>

## 관측 결과와 해석

원고의 단일·반복·잡음 결과를 각각 해당 분할·시드와 연결해 읽습니다. Strict Acc의 누락·추가 조건을 확인하고 mAP와 구분합니다. 표시된 그래프보다 CSV/JSON의 원정 밀도와 조건이 우선 근거입니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

함수별 역할은 차수 상세의 파일·핵심 정의에서 확인합니다. 검토 도구 check_review.py는 10개 항목과 원고·결과해 시·지표·분할·표시 조건을 확인합니다. 그 통과 범위를 전체 실험 승인으로 확대하지 않습니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

현재 다운로드는 최종 전체 원고·발표로 연결되며 과거 단계의 차이는 기존 전체 비교에 남아 있습니다. 원고 3장/5장/요약 구분과 발표 대본 수정을 독립 성능 실험으로 세지 않습니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

내부 9~20 그룹 중복과 독립 로 트 부재를 결과 옆에 기록합니다. 캐시와 저장 결과의 실행 조건을 확인하고 없는 제조 자료를 제공된 입력처럼 쓰지 않습니다. 지표 이름이 같아도 다른 실행을 합치지 않습니다.

### LEVEL 3 · 영상 크기와 학습·분할 조건

영상/라벨 대응, 초기400/100,368 그룹의 5fold와 내부 중복을 확인한 뒤30/1280/b8/p15 설정을 기록하세요. 노트북의 100epoch 기준 실험을 논문 30epoch 조건과 합치지 않습니다. 재학습과 저장결과 재도표를 구분합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 영상 500장·2944×2352 | 초기에는 학습 400장·검증 100장으로 나눕니다.<br>사진 크기와 장수는 서로 다른 단위이며, 볼 상자 라벨이 별도로 필요합니다. |
| <a id="layout18-table-3-row-2"></a> 368개 근접 중복 그룹·외부 5fold | 닮은 사진이 바깥 평가의 학습/시험 양쪽에 퍼지지 않도록 그룹으로 묶어 다섯 겹 비교를 합니다.<br>그러나 내부 train/val에는 9~20개 유사 그룹 중복이 남아 결과가 낙관적일 수 있습니다. |
| <a id="layout18-table-3-row-3"></a> YOLOv8n·30epoch·입력 1280·batch8·patience15 | 입력은 모델에 넣을 크기,batch는 한 갱신에 묶는 영상 수,epoch는 전체 자료 반복 단위입니다.patience15는 개선을 기다리는 조기 종료 설정입니다.<br>최대한 도와 실제 종료를 구분합니다. |
| <a id="layout18-table-3-row-4"></a> 실험 범위 | 일반 영상은 원본 +단일 10 종 +순차 조합 5 종, 잡음비교는 원본 +단일 필터입니다.<br>조건마다 다시 학습하므로 고정 모델에 처음 보는 잡음을 넣는 외부 강건성 시험과 다릅니다. |

### LEVEL 3·상자 검출·Strict Acc·OK/NG의 차이

평가 셀에서 conf/NMS를 각각 확인하고 Strict의 긴 변 0.5 중심 거리와 일대일 대응을 대조하세요. 실제 OK/NG 정답인지 라벨 규칙으로 만든 기준인지 확인해야 합니다. 같은 영상의 두 방법 비교에는 McNemar와 정오답 쌍을 함께 봅니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> mAP50-95 조건 | conf0.001·NMS IoU0.7로 볼 상자 검출을 평가합니다.conf는 예측을 남길 신뢰 도 문턱,NMS IoU는 겹친 예측을 정리하는 기준입니다.<br>평가 이름의 IoU 범위와 NMS 설정을 혼동하지 않습니다. |
| <a id="layout18-table-4-row-2"></a> Strict Acc 조건 | conf0.25·NMS IoU0.5입니다.<br>주석/예측 중심을 가까운 순서로 일 대 일 대응시키며 허용 거리는 주석 상자 긴 변의 0.5 배입니다.<br>볼을 모두 찾고 추가 검출도 없는 영상 비율입니다. |
| <a id="layout18-table-4-row-3"></a> 별도 OK/NG 규칙 | 중앙 부품 영역에서 위 5·왼쪽 4·아래 2·오른쪽 2개 규칙으로 판정합니다.<br>라벨 상자에도 같은 규칙을 적용한 정답과의 일치율은 전문가의 별도 불량 판정 정확도가 아닙니다. |
| <a id="layout18-table-4-row-4"></a> 평가의 기준과 보조 분석 | mAP는 상자의 겹침,Strict는 중심 대응·누락/추가, OK/NG는 개수 규칙을 평가합니다.<br>다수 클래스 기준은 불균형의 단순 기준,McNemar 는 같은 영상에 대한 두 방법의 정오답 차이를 봅니다.<br>실제 정답 CSV를 쓸 때 OKNG_CSV·REAL_LABEL_*을 확인합니다. |

### LEVEL 3 · 필터 순서와 고정 파라미터

실험 셀의 필터 목록과 숫자 파라미터를 먼저 기록한 뒤 같은 분할·시드·모델 조건으로 비교했는지 확인하세요. 잡음 표에서 조합 5개까지 모두 시험했다고 넓히지 않습니다. 볼 추가/삭제 진단은 주 연구 결과와 별도로 읽습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> 단일 10 종 | Invert,Otsu,Solarize,Histogram Equalization,CLAHE,Gamma,Gaussian Blur,Sobel,Emboss,Unsharp를 원본과 비교합니다.<br>영상 밝기·분포·흐림·경계를 바꾸는 서로 다른 처리입니다. |
| <a id="layout18-table-5-row-2"></a> 조합 5 종 | Invert +CLAHE,Blur +Otsu,Sobel +Invert,HistEq +Emboss,Unsharp +Sobel입니다.<br>A +B는 A 다음 B의 순서이며 역순이나 모든 가능 조합을 시험한 것은 아닙니다. |
| <a id="layout18-table-5-row-3"></a> 비교에 고정한 설정 | CLAHE clip40·16×16 격자,Gamma0.3,Gaussian Blur σ20·121×121 커널,Emboss gain4,Unsharp amount8·σ2입니다.<br>실험에서 사용한 값이지 전 환경 최적 값은 아닙니다. |
| <a id="layout18-table-5-row-4"></a> 도구와 추가 진단 | OpenCV는 영상,PyTorch/Kornia는 필터,Ultralytics는 검출,NumPy/pandas/Matplotlib는 집계/그림을 맡습니다.<br>노트북의 볼 삭제/추가·임계 값·분포·해상도·데이터 양 분석은 논문의 주 비교와 구분합니다. |

### LEVEL 3 · 단일 실행·시드 반복·잡음 결과

### LEVEL 3 · 저장 결과·새 학습·발표 자료의 사용법

루트에서 원문 명령으로 노트북을 열고 자료 경로·라벨 대응·GPU·캐시를 먼저 확인하세요. 저장표재도표라면새 학습을 시작할 필요가 없습니다. 발표 검사에는 해당 차수의 JSON/차트/사진 manifest와 PPTX 등 입력이 별도로 필요합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-7-row-1"></a> 새 학습 준비 | Python/CUDA PyTorch와 영상/YOLO 라벨이 필요합니다.<br>REQUIRE_GPU =True이면 CUDA가 없을 때 중단합니다.<br>원래/root/추계 학술 대회/DataSet 경로를 실제 위치로 맞추고 train/val/test images·labels와 data.yaml을 확인합니다. |
| <a id="layout18-table-7-row-2"></a> 라벨과 출력 | 라벨 행은 class cx cy w h 이며 좌표는 0~1 정규화입니다.<br>CSV/JSON·혼동 행렬·GPU 로그를 같은 조건의 결과로 확인하고 나서 그림을 만듭니다.<br>원영상/가중치/완성 환경은 별도 준비입니다. |
| <a id="layout18-table-7-row-3"></a> 실패 확인 | CUDA 오류는 드라이버/PyTorch 장치, 경로 오류는 Linux 기본 경로, 높은 점수는 중복/불균형/정답 정의, 수치 차이는 시드/분할/가중치/캐시/필터 값, 한글 깨짐은 폰트를 확인합니다. |
| <a id="layout18-table-7-row-4"></a> 문서와 발표 이력 | 논문 1~3차는 원고 변화,4차는 검토 도구,5차는 저장 표/코드 재구성입니다.<br>발표 1차 12 본장 +3 부록·600초 →2차 20장·600초 →3차 투명 로고/자산 →4차 대본 →최종 20장 PDF/PPTX입니다.<br>슬라이드/대본 변경을 새 학습으로 세지 않습니다. |
