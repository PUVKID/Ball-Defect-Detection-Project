## 최신 발표·7차

**마지막 장은 감사 인사 중심으로 정리했습니다.** 질의응답 문구와 하단 네 파트 안내·선을 제거하고, 감사 인사·저자·학교 마크·페이지 번호를 유지했습니다.  
다른 19장과 연구 수치·대본·사진은 유지합니다.

| 차수 | 변경 | 자료 |
| --- | --- | --- |
| 발표 자료 7차 | 마지막 장의 보조 문구·안내 선 정리 | [PPTX·PDF](../../발표자료/7차) · [상세](../../docs/revisions/talk-7.md) · [직전 비교](../../docs/revision-diffs/talk-7.md) |

[5차 대본·질문과 답변·연구 이해·사진모음·논문 정정 안내](../../발표자료/5차)는 함께 사용합니다. 기존 6차 발표도 보존합니다.


<a id="현재-발표--6차"></a>

## 발표 시각 개선·6차

**6차 슬라이드는 아래 자료에 보존했습니다.** 파트 구분과 도식 연결 선, 필터 별 색과 계열 표식·대비를 다듬었습니다.  
기존 5차의 10분 대본·질문과 답변·연구 이해·사진 모음·정정 안내는 함께 사용합니다.

| 자료 | 역할 | 연결 |
| --- | --- | --- |
| 6차 PPTX·PDF | 현재 발표·편집 원본 | [파일](../../발표자료/6차) · [상세](../../docs/revisions/talk-6.md) |
| 5차 준비 자료 | 대본·질의 응답·이해·사진·논문 정정 안내 | [기존 자료](../../발표자료/5차) |


**단일·복합 필터와 잡음·시드 결과를 20장으로 설명하는 완성 발표 PDF/PPTX입니다.** 논문과 다른 목적의 발표 자료로 같은 연구의 흐름을 전달합니다.

| 주요 구성 | 내용 |
| --- | --- |
| 연구 흐름 | 자료와 그룹 평가에서 시작해 필터·두 지표·잡음·한계로 이어집니다. |
| 그림과 차트 | 단일·복합·잡음·반복 결과를 같은 기준의 표와 그림으로 설명합니다. |
| 편집 원본 | PDF와 같은 발표의 PPTX를 함께 제공합니다. |
| 대본 대응 | 4차 완성 대본과 장별 순서·발화 내용을 함께 읽습니다. |

<a id="-이용-순서"></a>

## 이용 순서

1. PDF에서 전체 연구 흐름을 먼저 읽습니다.
2. 각 차트의 조건·지표·원정밀도 근거를 논문 및 결과표와 대조합니다.
3. PPTX 노트와 4차 대본의 장별 발화를 확인합니다.
4. 필요한 편집은 원본 발표를 별도 사본으로 보관해 진행합니다.
