**필터 비교 연구를 12장 본발표 600초와 3장 부록으로 설명한 초기 발표 구성입니다.**

**주요 구성**

연구 이야기

**내용**

자료·그룹 평가→필터→mAP/Strict Acc→잡음·시드→한계 순서로 설명합니다.


**주요 구성**

발표 분량

**내용**

검사기는 15장, 앞 12장 시간 합계 600초와 부록 0초를 확인합니다.


**주요 구성**

원정밀도 차트

**내용**

검사기는 JSON 수치와 PPTX 차트의 15유효자리 및 1·2자리 표시를 대조합니다.


**주요 구성**

발화 대응

**내용**

슬라이드 노트와 대본에 같은 발화문이 있는지 확인하는 경로를 포함합니다.



<a id="-이용-순서"></a>

## 이용 순서

1. 이 차수의 변경 설명을 읽고 현재 최종 PDF에서 대응되는 발표 흐름을 봅니다.
2. 도입·방법·필터 비교·잡음·한계가 어떤 순서로 전달되는지 확인합니다.
3. PPTX 노트와 완성 대본의 장별 발화를 확인합니다.
4. 검사 도구를 이용하려면 입력 JSON·원자료·발표 파일의 경로를 먼저 준비합니다.
